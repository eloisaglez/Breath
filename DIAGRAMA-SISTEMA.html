📋 FASE ACTUAL - Flujo de Trabajo OPERATIVO

1
Profesores crean códigos (OFFLINE)
Abren generar-codigos.html en su ordenador local. Generan códigos con descripción y puntos (5-50 pts). Pueden crear códigos múltiples de una vez (ej: 30 códigos de 10 puntos).
2
Descargar codigos.json
Al terminar de crear códigos, hacen clic en "Descargar codigos.json". Obtienen un archivo JSON con TODOS los códigos válidos.
3
Subir a GitHub
Suben (o actualizan) el archivo codigos.json a GitHub. Este archivo contiene todos los códigos válidos que los alumnos pueden usar. El archivo está "oculto" - no hay enlaces visibles a él en la web.
4
Distribuir códigos a los alumnos
El profesor entrega los códigos cuando y como quiera:
📄 Físico: Tarjetas impresas, post-its, fichas
📧 Digital: Email, Classroom, Moodle
🎯 En clase: Proyectado, dictado, premio por tarea
🎁 Oculto: Dentro de ejercicios, como recompensa
5
Alumnos introducen códigos
Los alumnos acceden a index.html en la web. Seleccionan su curso (3º ESO A/B/C/D/E). Introducen el código que les dio el profesor. El sistema verifica contra codigos.json (carga automática en segundo plano).
6
Validación y puntos
Si el código es válido y NO ha sido usado: ✅ Suma puntos al curso en Firebase. Si el código ya fue usado: ❌ Mensaje de error. Si el código no existe: ❌ Mensaje de código inválido. Los datos se guardan en Firebase en tiempo real.
7
Visualización en pantallas
pantalla.html muestra los tanques de oxígeno en tiempo real. Se actualiza automáticamente desde Firebase. Muestra ranking, porcentajes y estadísticas globales. Ideal para pantallas del centro en modo pantalla completa (F11).

🚀 FASE 2 - Flujo Futuro Automatizado EN DESARROLLO

1
🔐 Acceso al panel de profesor
El profesor accede a panel-profesor.html online. Introduce contraseña para acceso seguro. Puede acceder desde cualquier dispositivo con internet.
2
⚡ Crear códigos en tiempo real
Crea códigos directamente en la web. Se guardan automáticamente en Firebase. Sin necesidad de descargar/subir archivos. Disponibles instantáneamente para los alumnos.
3
📊 Gestión y estadísticas
Ve códigos activos/usados en tiempo real. Elimina códigos sobre la marcha si es necesario. Estadísticas de uso por curso. Todo sincronizado automáticamente.
4
🎯 Resto del flujo igual
El profesor distribuye códigos como en Fase 1 (físico/digital). Los alumnos introducen códigos igual que antes. Las pantallas siguen mostrando tanques en tiempo real. La experiencia del alumno NO cambia.
🔑 IMPORTANTE: Seguridad de códigos

¿Los alumnos pueden ver codigos.json o la lista de códigos?

En ambas fases: Los alumnos NUNCA ven la lista de códigos.

  • ✅ Solo ven una caja para introducir el código
  • ✅ No hay enlaces visibles a codigos.json
  • ✅ Cada código solo se puede usar UNA vez
  • ✅ Solo los profesores tienen acceso al generador/panel
  • ✅ El profesor controla 100% la distribución

🔄 Actualizar códigos

FASE 1 - Añadir más códigos después de publicar:

  1. Descarga el codigos.json actual de GitHub
  2. Abre generar-codigos.html en tu ordenador
  3. Haz clic en "Cargar códigos desde archivo"
  4. Carga el JSON que descargaste
  5. Añade los nuevos códigos
  6. Descarga el JSON actualizado
  7. Sube el nuevo archivo a GitHub (reemplaza el anterior)

FASE 2 - Añadir códigos (futuro):

  1. Accede al panel de profesor online
  2. Introduce contraseña
  3. Crea nuevos códigos
  4. ¡Listo! Automáticamente disponibles
