🚀 Sistema Misión Oxígeno - Diagrama de Funcionamiento

👥 Actores del Sistema

👨‍🏫
PROFESORES
Generan códigos válidos usando la herramienta offline. Deciden puntos y descripciones.
🎓
ESTUDIANTES
Introducen códigos en la web para ganar puntos de oxígeno para su curso.
📺
PANTALLAS
Muestran en tiempo real los tanques de todos los cursos en competición.

📝 Flujo de Trabajo

1
Profesores crean códigos (OFFLINE)
Abren generar-codigos.html en su ordenador local. Generan códigos con descripción y puntos (5-50 pts). Pueden crear códigos múltiples de una vez (ej: 30 códigos de 10 puntos).
2
Descargar codigos.json
Al terminar de crear códigos, hacen clic en "Descargar codigos.json". Obtienen un archivo JSON con TODOS los códigos válidos.
3
Subir a GitHub
Suben (o actualizan) el archivo codigos.json a GitHub. Este archivo contiene todos los códigos válidos que los alumnos pueden usar. El archivo está "oculto" - no hay enlaces visibles a él en la web.
4
Alumnos introducen códigos
Los alumnos acceden a estudiantes.html (index.html en GitHub). Seleccionan su curso (3º ESO A/B/C/D/E). Introducen el código que les dio el profesor. El sistema verifica contra codigos.json (carga automática en segundo plano).
5
Validación y puntos
Si el código es válido y NO ha sido usado: ✅ Suma puntos al curso. Si el código ya fue usado: ❌ Mensaje de error. Si el código no existe: ❌ Mensaje de código inválido. Los datos se guardan en localStorage del navegador.
6
Visualización en pantallas
pantalla.html muestra los 5 tanques de oxígeno en tiempo real. Se actualiza automáticamente cada 3 segundos. Muestra ranking, medallas, porcentajes y estadísticas globales. Ideal para poner en pantallas del centro en modo pantalla completa (F11).
⚠️ IMPORTANTE: Renombrar archivo
Cuando subas estudiantes.html a GitHub, debes renombrarlo a index.html. GitHub Pages busca automáticamente un archivo llamado index.html como página principal.

📁 Archivos del Sistema

📄 estudiantes.html
Interfaz para alumnos. Permite introducir código y curso.
Subir a GitHub como: index.html
📺 pantalla.html
Dashboard con todos los tanques. Muestra competición en tiempo real.
Subir a GitHub
🔧 generar-codigos.html
Herramienta para profesores. Genera códigos y archivo JSON.
NO subir a GitHub - Solo uso local
🔑 codigos.json
Base de datos de códigos válidos. Los alumnos NO lo ven directamente.
Subir a GitHub - Se actualiza cada vez que generas códigos nuevos

🔒 Seguridad

¿Los alumnos pueden ver codigos.json?

Técnicamente sí, si saben buscar. PERO:

  • ✅ No hay enlaces visibles en las páginas
  • ✅ Cada código solo se puede usar UNA vez
  • ✅ Solo los profesores tienen la herramienta de generar códigos
  • ✅ Puedes generar códigos únicos para cada alumno/tarea

Recomendación: Genera códigos únicos y solo entrégalos a quien complete la tarea.

🔄 Actualizar códigos

Si necesitas añadir más códigos después de publicar:

  1. Descarga el codigos.json actual de GitHub
  2. Abre generar-codigos.html en tu ordenador
  3. Haz clic en "Cargar códigos desde archivo"
  4. Carga el JSON que descargaste
  5. Añade los nuevos códigos
  6. Descarga el JSON actualizado
  7. Sube el nuevo archivo a GitHub (reemplaza el anterior)

Los alumnos verán los nuevos códigos inmediatamente (sin necesidad de actualizar las páginas HTML).
