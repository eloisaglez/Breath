## 🎓 En Clase: Cómo Evaluar

### Paso 1: Grupo Completa la Actividad

Ejemplo: 3º ESO A, Grupo 2 termina Actividad 1 de F&Q

### Paso 2: Evalúas la Calidad

Miras tu archivo `FyQ_3_ESO_A.txt`:

```
ACTIVIDAD 1
  Grupo_2:
    1_puntos → ABC12345
    2_puntos → XYZ67890
    3_puntos → DEF24680
```

### Paso 3: Decides los Puntos

Según la calidad del trabajo:

| Calidad | Puntos | Código a dar |
|---------|--------|--------------|
| **Regular/Básico** | 1 punto | ABC12345 |
| **Bien hecho** | 2 puntos | XYZ67890 |
| **Excelente (100%)** | 3 puntos | DEF24680 |

### Paso 4: Das el Código al Grupo

Puedes:
- 📝 Escribirlo en la pizarra
- 🗣️ Dictarlo
- 📄 Dárselo en papel
- 📧 Enviarlo por Classroom
- Lo que prefieras

### Paso 5: El Grupo lo Introduce

Los alumnos:
1. Abren la web del proyecto
2. Seleccionan su clase (3º ESO A)
3. Introducen el código
4. ¡Ven cómo sube el tanque de su clase!

### Paso 6: Marcas el Código (Importante)

**Tacha o marca** el código que diste para no darlo dos veces.

## ⚠️ Reglas Importantes

### 1. Cada Código Solo se Usa UNA Vez

- ✅ Un grupo lo usa → Funciona
- ❌ Otro grupo intenta usarlo → "Código ya usado"

Por eso es importante marcar los códigos que das.

### 2. Los Códigos son por Clase

Un código de 3º ESO A **NO funciona** para 3º ESO B.

El sistema lo valida automáticamente.

### 3. Evalúa con Honestidad

El sistema funciona mejor si:
- Eres consistente en tu evaluación
- Das 3 puntos solo al trabajo excelente
- Das 1 punto al trabajo básico/regular
- Das 2 puntos al buen trabajo

### 4. Los Puntos Ya Están Normalizados

No te preocupes porque algunas clases tienen 7 grupos y otras 8.

El sistema **normaliza automáticamente** para que sea justo.

## 🔢 Sobre los Puntos

### Sistema de Normalización

**Problema:**
- 3º ESO A, B, F tienen 7 grupos
- 3º ESO C, D, E tienen 8 grupos
- Sin normalización, las clases de 8 grupos tendrían ventaja (14.3%)

**Solución (Automática):**
- Clases de 7 grupos: puntos × 1.143
- Clases de 8 grupos: puntos × 1.0

**Ejemplo:**
- 3º ESO A (7 grupos) suma 10 puntos → Sistema registra 11.43 puntos
- 3º ESO C (8 grupos) suma 10 puntos → Sistema registra 10 puntos

**Resultado:**
Todas las clases pueden llegar al 100% (240 puntos normalizados)

**Transparente:**
Los alumnos NO ven la normalización, solo sus puntos reales.

## ❓ Preguntas Frecuentes

### P: ¿Qué pasa si me equivoco y doy el código incorrecto?

**R:** El código se marca como usado. Contacta al coordinador para corregirlo en Firebase. Mejor prevenir siendo cuidadoso.

### P: ¿Puedo dar todos los códigos de 3 puntos?

**R:** Técnicamente sí, pero el sistema funciona mejor con honestidad en la evaluación.

### P: ¿Y si un grupo pierde su código?

**R:** Puedes dictárselo de nuevo. El código no se invalida hasta que se introduce en el sistema.

### P: ¿Los alumnos pueden ver mi lista de códigos?

**R:** No, si manejas los archivos correctamente. Tú decides cuándo y a quién dar cada código.

### P: ¿Puedo dar las actividades en el orden que quiera?

**R:** Sí. El sistema acepta cualquier código válido en cualquier momento.

### P: ¿Qué hago si un alumno hace trampa con un código?

**R:** Cada código solo funciona UNA vez. Si alguien intenta usar un código ya usado, el sistema lo rechaza. Si detectas otra trampa, informa al coordinador.
